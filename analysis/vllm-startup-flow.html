下面按真实调用顺序展开主链路，并把启动分支也放入同一张调用图。 每一行都标明调用方、被调用方、执行模型、关键入参、返回值或副作用，以及下一跳； 行末附文件绝对路径、所属类或模块，以及可点击的源码行链接。

SYNC当前调用栈内同步返回 ASYNC事件循环中 await / async context WAIT调用方阻塞等待结果 RPC跨进程请求与响应 PROCESS创建或进入新进程 THREAD启动后台线程 TASK创建 asyncio task BRANCH条件分支，不进入默认主链

  2. B · Socket 与配置bind → VllmConfig
  3. C · EngineCore 启动AsyncLLM → handshake
  4. D · Executor / Workerdevice → runner
  5. E · 模型加载model → weights
  6. F · KV 与 readyprofile → ready

进程启动与就绪的精确顺序

  1. MPClient.__init__ 在没有外部 `client_addresses` 时，自己分配地址、绑定前端 ZMQ socket，并进入 launch_core_engines。
